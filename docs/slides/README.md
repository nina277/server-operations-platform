# 発表資料

`presentation.pptx` が発表用のスライド(18枚 / 10〜15分想定)。
**PowerPointで直接編集してよい。**細かな調整は手で行うほうが早い。

## 構成

| # | 内容 |
|---|---|
| 1 | 表紙 |
| 2〜3 | 背景と課題 / 目的と範囲 |
| 4 | システム構成 |
| 5〜7 | 設計の中心(操作を4つに固定 / 自動実行の6条件) |
| 8〜9 | 障害検知の流れ / 検証の設計 |
| 10 | 成果(成功基準9項目) |
| 11〜15 | **動かして初めて分かったこと**(この資料の山場) |
| 16 | 結論 |
| 17〜18 | 付録(技術構成 / 見つけた不具合の一覧) |

**全スライドに発表者ノートを入れてある。**話す内容の下書きとして使う。

内容の出どころは [../design.md](../design.md)。
数値(試験件数・成功基準・実測値)はすべて実際の測定結果で、
出どころは [../verification.md](../verification.md) にある。

## 作り直すとき

大きく作り替える場合のみ。`build-slides.js` から生成する。

```bash
npm install pptxgenjs
node build-slides.js presentation.pptx
```

**フォントは Meiryo を指定している。**Windows標準で、日本語が確実に出るため。
別の環境で開くときは置き換えが要るかもしれない。

配色は次の4色で組んでいる。

| 用途 | 色 |
|---|---|
| 地(暗い面・強調) | `0F1E2B` |
| 補助(カード・区切り) | `EEF2F6` |
| 指摘・発見 | `C4471F` |
| 達成・正常 | `1B6B5E` |
